## Command Category: Globalchat

### `/globalchat`

**Description:** Manage global chat settings for this server

### Usage

`/globalchat info`
`/globalchat remove`
`/globalchat setup [channel]`

### Subcommands

**`/globalchat info`**
> Show stats and information for the Kythia Global Chat network!


**`/globalchat remove`**
> Remove this server from the global chat network


**`/globalchat setup [<channel>]`**
> Setup a global chat channel for cross-server interaction

**Options for this subcommand:**
- **`channel`**
  - **Description:** Select a channel for global chat (optional)
  - **Type:** Channel
