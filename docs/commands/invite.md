## Command Category: Invite

### `/invites`

**Description:** 🔗 Manage invites and rewards

### Usage

`/invites add <user> <number>`
`/invites leaderboard`
`/invites remove <user> <number>`
`/invites reset`
`/invites setting invite <channel>`
`/invites user [user]`

### Subcommands

**`/invites add <user> <number>`**
> Add invites to a user (Admin only)
> _User Permissions: `Administrator`, `ManageGuild`_

**Options for this subcommand:**
- **`user*`**
  - **Description:** User
  - **Type:** User
- **`number*`**
  - **Description:** Amount
  - **Type:** Integer
**`/invites leaderboard`**
> View top inviters leaderboard


**`/invites remove <user> <number>`**
> Remove invites from a user (Admin only)
> _User Permissions: `Administrator`, `ManageGuild`_

**Options for this subcommand:**
- **`user*`**
  - **Description:** User
  - **Type:** User
- **`number*`**
  - **Description:** Amount
  - **Type:** Integer
**`/invites reset`**
> Reset all invites for this server (Admin only)
> _User Permissions: `Administrator`, `ManageGuild`_


**`/invites setting invite <channel>`**
> 📢 Set invite log channel
> _User Permissions: `ManageGuild`_

**Options for this subcommand:**
- **`channel*`**
  - **Description:** Channel
  - **Type:** Channel
**`/invites user [<user>]`**
> Check user invites

**Options for this subcommand:**
- **`user`**
  - **Description:** User
  - **Type:** User
