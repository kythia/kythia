# Security Policy

## Supported Versions

We currently provide security updates for the following versions of Kythia:
| Version | Supported |
| ------- | ------------------ |
| v26.x.x | ✅ |
| < v1.x | ❌ |

## Reporting a Vulnerability

We take the security of the Kythia very seriously.
If you discover a security vulnerability within Kythia, please **DO NOT** create a public issue.

Instead, please send an e-mail to **kenndeclouv@gmail.com**. We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
